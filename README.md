# Restaurants-Analytics-Dashboard
An interactive Power BI dashboard built using a food delivery dataset to analyze key business metrics such as orders, revenue, customers, restaurant performance, and delivery trends. The project focuses on transforming raw data into meaningful business insights through data cleaning, modeling, DAX calculations, and interactive visualizations.

Tech Stack
The dashboard was built using the following tools and technologies:
Power BI Dekstop - Main data visualization platform used for report creation.
DAX (Data Analysis Expressions) - Used for calculated measures, dynamic visuals, and conditional logic.
Data Modeling - Relationships established among tables to enable cross-filtering and aggregation.
